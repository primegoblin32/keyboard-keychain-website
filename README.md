# Keyboard Keychain Website

A personal website featuring an interactive gallery of keyboard keychain designs, showcasing different combinations of keycap and base colors through images and animations.

## About

The website presents 25 keyboard keychain designs arranged in a 5×5 interactive gallery. Each design represents a unique combination of keycap and base colors, allowing visitors to browse through the available variations.

## Design

The website follows a minimal, full-screen layout that puts the keyboard keychain designs at the center of attention.

- **Dark Interface:** A black background provides contrast and keeps the focus on the designs.
- **Minimal Navigation:** Circular arrow buttons allow visitors to switch between keycap and base colors.
- **Color Labels:** Displays the currently selected keycap and base colors.
- **Hover Effects:** Navigation buttons reveal labels describing their functions.
- **Responsive Layout:** Adjusts image sizing, navigation placement, and spacing for mobile screens.
- **Image Presentation:** Uses centered images with adjustable scaling to accommodate different screen sizes.

## Features

- **5×5 Interactive Gallery:** 25 possible keycap and base color combinations.
- **Five Color Options:** Black, White, Silver, Orange, and Blue.
- **Animated Preview:** The first design includes four randomly selected looping video animations.
- **Sound Effects:** Random sound effects play when navigation arrows are clicked.
- **Mobile Compatibility:** Supports desktop and mobile browsers.
